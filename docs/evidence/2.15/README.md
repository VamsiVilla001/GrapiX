# 2.15 Named operator login for Playout

Built 19 November 2026 (user decision of 16 Nov 2026: the person, not only the credential). The row stays **active**: the formal as-run file is row 12.11, which is built on the audit line below.

## What was built
- **Contract** (`Shared/contracts/src/auth.rs`): `OperatorName` (trimmed; 1 to 64 characters; letters of any script, digits, space and `. ' - _`; starts with a letter or digit; no double space) and `OperatorNameFault`. Two named refusals: `OperatorRequired { request }` and `OperatorNameInvalid { request, fault }`. `Shared/contracts/fixtures/operator-names.json` is read by the Rust parser and the Playout page, so the two cannot disagree.
- **Wire** (`Shared/control-plane/src/message.rs`): the control `Envelope` has an optional `operator`, absent when not given, so an older reader reads the envelope as before; `ClientRequest::is_program_command()` is one exhaustive match (cue, take, clear, phase, configure output; not `Stop`).
- **Transport** (`Shared/control-transport`): `Client::set_operator` sends the name with a Program command and with nothing else, and keeps it across `reconnect` (a bug found while writing the tests: `reconnect` replaced the whole client and would have signed the person out). The server judges the credential and its scope first, then the operator, then hands the request to the engine: a Program command with no operator is refused `OperatorRequired`, a name the rules refuse `OperatorNameInvalid`, and neither reaches the engine. The refused name is not echoed.
- **Audit** (`control.program_command`, written for every Program command that reached the engine): request, operator, credential subject, role, result and refusal. Never the credential. Row 12.11's as-run record reads these fields.
- **Playout shell** (`Playout/shell`): the operator is held beside the connection, so a person can sign in before the engine is reachable and stays signed in across a reconnect; `cmd_sign_in`, `cmd_sign_out`, `cmd_operator`; every Program command goes through one path that refuses `OperatorRequired` locally when nobody is signed in and otherwise sends it for them; sign-in and sign-out are on the shell's log with the name.
- **Playout page** (`Playout/web`): an Operator field and Sign in / Sign out in the header; the transport is held under "NO OPERATOR" until someone signs in; a refusal named `operatorRequired` makes the page ask the shell who is signed in.
- **Other senders of Program commands** now sign in: the conformance suites, the mock Playout, the render-worker log test.

## Evidence
- `cargo test -p gx-contracts --lib`: 286 pass (fixture, fault words). `gx-control-plane --lib`: 76. `gx-control-transport`: 28 lib (a Program command is on record with the person and the credential, and the credential is in neither line) + 10 + 7 (`tests/operator.rs`: refused by name for each Program command and never reaches Program, signed-in may send, sign-out holds again and a reconnect keeps the person, reads need no operator, bad names name their rule and are not echoed, credential and scope are judged before the operator, an unauthenticated peer is asked to authenticate not to sign in) + 3.
- `cargo test -p gx-playout-shell --lib`: 10 pass, three runs; `node --test Playout/tests/operator.test.mjs`: 3 pass.
- Conformance: 632 passed, 0 failed, 9 skipped; one new check drives both refusals through a real server (the refusal audit lists them as driven).
- Seen in the browser pane with a fake shell: connected with nobody signed in shows "NO OPERATOR" and the buttons are disabled; a bad name is told at once and nothing is sent; a good name releases the transport and Take reaches the shell; a shell that loses the operator behind the page's back is refused by name and the page re-syncs to "signed out"; Sign out holds the transport again.
- 20 mutants, one at a time, each failed a named test: the server (no check, bad name accepted, audit line without the person, without the credential, or not written), the client (operator never sent, sent on reads, dropped on reconnect), the envelope (operator not serialised, phase or output change not a Program command), the name rules (length, double space, start, allowed set, trimming), the shell (check skipped, sign-out keeps the person, bad name signs in, sign-in logged without the name). Survivors on the first run: operator sent on reads (now a pure rule with its own test), one disallowed character (fixture cases added), and a redundant shell call (removed).
