# Phosphor UI icons

Unmodified regular-weight SVGs from `@phosphor-icons/core` 2.1.1, fetched from
the npm registry. Source: https://github.com/phosphor-icons/core.
MIT licence retained in `LICENSE`. These are local assets, with no CDN or
runtime icon-package dependency.

The tool and align icons (`tool-*.svg`, `align-*.svg`, `spread-*.svg`) are not Phosphor's: they are drawn for GrapiX on the same 256 grid with a 16 px round stroke, so they sit beside the others. Nothing was downloaded for them.
