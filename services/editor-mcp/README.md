# Editor MCP

Run `cargo run -p gx-editor-mcp -- --root <project-store-folder>` to expose
the Editor's authoring tools over newline-delimited JSON-RPC on stdio.
Configure a client to launch the built `gx-editor-mcp` binary with those two
arguments. The launching process grants access to that project-store root;
the server has only the Author scope and no Program-control connection.

`tools/list` advertises installed handlers, with `inputSchema` generated from
the Rust types the handlers parse. The same schemas are checked in under
`Shared/generated-ts/schemas/mcp/` and regenerated by `npm run codegen`.
The metadata's `input` type name is retained for existing clients.

Without an engine capability exchange, this standalone process declares no
material support to preflight. It does not invent renderer capabilities.
